Pilihan Model LLM per VRAM — cek dengan nvidia-smi

4 GB
  • gemma3:4b / qwen2.5:3b (Q4)
  • Potongan ±2.000 token
  • Cukup untuk ekstraksi, ringkasan lebih sederhana
6 GB
  • qwen2.5:7b Q4 (sebagian offload ke CPU)
  • gemma3:4b penuh di GPU
  • Potongan ±3.000 token
8 GB
  • qwen3:8b / qwen2.5:7b Q4_K_M
  • Sahabat-AI 8B (khusus bahasa Indonesia)
  • Konteks 8k, potongan ±4.000 token

Roadmap Development

Selesai — STT + Speaker sudah jalan

  • GUI desktop, progress bar, GPU CUDA 12.8
  • Model maleo, addon WhisperX (diarization butuh accept HF agreement)

STATUS: DITAHAN prioritas sekarang: web portal + Docker

  • Fase LLM/MoM di bawah ini dikerjakan setelah portal stabil
  • LLM akan ditempatkan di server terpisah, portal hanya memanggil API-nya

Fase 0 — Persiapan ½–1 hari

  • Cek VRAM, instal Ollama, OLLAMA_MODELS ke D:/E:
  • Siapkan 2–3 transkrip rapat nyata + 1 MoM manual sebagai pembanding

Fase 1 — Prototipe CLI 1–2 hari

  • py -3.12 -m app.mom output/xxx.json → MoM Markdown
  • Bandingkan 2–3 model, pilih yang paling akurat untuk action item

Fase 2 — Kualitas 2–3 hari

  • JSON schema + retry, dedupe di tahap reduce
  • Glosarium istilah/nama proyek, mapping speaker → nama + jabatan

Fase 3 — Integrasi GUI 2 hari

  • Tab "MoM": pilih transkrip, metadata rapat, mapping speaker, Generate + progress
  • Preview yang bisa diedit, export DOCX/MD

Fase 4 — Opsional sesuai kebutuhan

  • Toggle provider cloud untuk rapat yang tidak sensitif
  • Buat ulang per bagian, beberapa template MoM

Catatan Penting

VRAM dipakai bergantianLepas model Whisper sebelum LLM dimuat, karena GPU tidak cukup untuk keduanya sekaligus.
Drive C: hampir penuhSimpan model LLM di D:/E: lewat OLLAMA_MODELS.
Label speaker = kualitas PICTanpa diarization, PIC action item sering kosong atau salah.
Timestamp sebagai rujukanSetiap poin MoM punya timestamp untuk dicek ke rekaman, menahan halusinasi.
